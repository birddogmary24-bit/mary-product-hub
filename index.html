데이터 동기화 & API 키 안전 등록 안내

이 Product Hub는 file:// 로컬 환경과 정적 GitHub Pages에서 모두 동작하는 구조입니다. 저장소 루트에서 동기화 스크립트를 실행하면 Supabase · Amplitude · Langfuse 통계, 비용, RAG 로그가 비식별 처리되어 08~11 문서와 hub-bundle.js에 반영됩니다.

1. 허브 데이터 동기화 실행

npm run hub:pages

2. Amplitude Read Secret & Langfuse 키 안전 등록 (터미널 입력 숨김)

채팅창에 키를 붙여넣지 말고 로컬 터미널에서 아래 명령으로 .env.local에 추가한 뒤 npm run hub:sync를 다시 실행하세요. (Git/Vercel에는 업로드되지 않도록 무시 설정되어 있습니다.) 

npm run hub:pages

보안 원칙: product-hub/data/는 .gitignore 및 .vercelignore에 등록되어 있으며, 동기화 시 assertZeroSensitiveLeaks() 스캐너가 PII·시크릿·계정·로컬 경로 노출 여부를 자동 검증합니다.
